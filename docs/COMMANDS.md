# Commands and permissions

| Command | Behavior | Permission |
|---|---|---|
| `/bannerbuilder` | Open Loom+ | `bannerbuilder.use` |
| `/bbanner` | Alias for `/bannerbuilder` | `bannerbuilder.use` |
| `/bannershop` | Alias for `/bannerbuilder` | `bannerbuilder.use` |
| `/loomplus` | Alias for `/bannerbuilder` | `bannerbuilder.use` |

## Discount permissions

| Permission | Default discount | Default access |
|---|---:|---|
| `bannerbuilder.discount.vip` | 10% | false |
| `bannerbuilder.discount.mvp` | 25% | false |
| `bannerbuilder.discount.admin` | 100% | false |

The discount amounts and permission nodes are editable under `discounts.ranks` in `config.yml`. `bannerbuilder.use` defaults to `true`.
